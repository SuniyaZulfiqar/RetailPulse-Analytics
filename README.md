# RetailPulse Analytics

## End-to-End Retail Sales Analytics Project

RetailPulse Analytics is an end-to-end business intelligence and data analytics project focused on analyzing retail sales performance, customer behavior, product profitability, store performance, and revenue trends.

The project demonstrates a complete analytics workflow, from data preparation and SQL analysis to Python-based exploratory data analysis and interactive Power BI visualization.

---

## Business Problem

Retail businesses generate large amounts of sales data, but raw data alone does not provide actionable business insights.

This project analyzes retail sales data to answer important business questions:

- Which customers generate the most revenue?
- Which products perform best?
- Which products are loss-making?
- How does revenue change over time?
- Which cities generate the most revenue?
- Which membership levels contribute the most spending?
- Which stores perform best?
- Which employees contribute most to business performance?
